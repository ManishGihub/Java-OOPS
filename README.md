# ☕ Java OOPs

A beginner-friendly repository to understand the **Object-Oriented Programming (OOP)** concepts in Java through simple and easy-to-understand examples.

## 📚 Topics Covered

* ✅ Classes & Objects
* ✅ Constructors
* ✅ Getter & Setter (Encapsulation)
* ✅ Inheritance
* ✅ Abstraction
* ✅ Interfaces
* ✅ Compile-Time Polymorphism (Method Overloading)
* ✅ Run-Time Polymorphism (Method Overriding)

---

## 📂 Repository Structure

| Java File              | Concept                   | Description                                                                      |
| ---------------------- | ------------------------- | -------------------------------------------------------------------------------- |
| `ClassObj.java`        | Classes & Objects         | Demonstrates object creation, instance variables, and methods.                   |
| `Constructor.java`     | Constructors              | Shows default, parameterized, and copy constructors.                             |
| `GetterSetter.java`    | Encapsulation             | Demonstrates data hiding using private variables with getters and setters.       |

## 🧠 OOP Concepts Explained

### 1️⃣ Classes & Objects

A **class** is a blueprint for creating objects, while an **object** is an instance of a class.

**Example:** `ClassObj.java`

Features:

* Object creation
* Instance variables
* Methods
* `this` keyword

---

### 2️⃣ Constructors

Constructors are special methods that initialize objects.

This project demonstrates:

* Default Constructor
* Parameterized Constructor
* Copy Constructor

**Example:** `Constructor.java`

---

### 3️⃣ Encapsulation

Encapsulation protects data by keeping variables private and accessing them through public methods.

**Example:** `GetterSetter.java`

Concepts covered:

* `private` variables
* Getter methods
* Setter methods

---

### 4️⃣ Inheritance

Inheritance allows one class to acquire the properties and behaviors of another class.

This example demonstrates:

* Single Inheritance
* Multilevel Inheritance
* Hierarchical Inheritance

**Example:** `Inheritance.java`

---

### 5️⃣ Abstraction

Abstraction hides implementation details and exposes only the essential functionality.

Implemented using:

* Abstract class
* Abstract methods
* Constructor chaining

**Example:** `Abstraction.java`

---

### 6️⃣ Interfaces

Interfaces define a contract that implementing classes must follow.

Features demonstrated:

* Interface implementation
* Multiple inheritance using interfaces

**Example:** `Interfaces.java`

---

### 7️⃣ Compile-Time Polymorphism

Also known as **Method Overloading**.

The same method name performs different operations depending on the parameters.

**Example:** `CompiletimePoly.java`

---

### 8️⃣ Run-Time Polymorphism

Also known as **Method Overriding**.

The method to execute is determined during runtime.

**Example:** `RuntimePoly.java`

---

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/<your-username>/java-oops.git
```

Go to the project directory:

```bash
cd java-oops
```

Compile any Java file:

```bash
javac ClassObj.java
```

Run the program:

```bash
java ClassObj
```

Replace `ClassObj` with the name of any Java file you want to execute.
